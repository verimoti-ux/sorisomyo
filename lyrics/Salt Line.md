# Salt Line

- **앨범:** 소금 자국 / Salt Line
- **시리즈:** Electric Folklore
- **장르:** 슬로우 EDM 발라드 (알란 워커 스타일)

## 수노 스타일 프롬프트

```
slow melodic EDM ballad, 90 BPM, minor key, airy breathy female vocal, soft piano intro, plucked synth arpeggio, wide supersaw pads, warm sub bass, gentle sidechain pump, emotional build-up, melodic future bass drop with pitched vocal chops, Nordic cinematic atmosphere, melancholic but hopeful
```

## 제외 스타일 (Exclude Styles)

```
rap, trap hi-hats, dubstep growl, heavy distortion, aggressive drums, male vocal, acoustic folk
```
